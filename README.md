# LBA-UNet

Lightweight boundary-aware segmentation for medical images, designed for
edge / embedded deployment.

> **Status: code release pending.**
> This repository is a placeholder. The full implementation, training and
> evaluation scripts, and pretrained checkpoints will be published here
> after the paper is accepted.

## At a glance
- Lightweight encoder-decoder design for real-time inference on
  resource-constrained devices.
- Boundary-aware design for accurate lesion contours at low computational cost.
- Evaluated on ISIC2018, Kvasir-SEG and CVC-ClinicDB.
